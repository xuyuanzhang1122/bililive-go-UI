# v2.1.2-rc.2 测试版

本版统一录播目录、稳定来源身份、播放会话与 Web 契约，修复并发播放资产发布、会话刷新与历史治理边界。用于测试验证，保留原录制配置和源文件。

## 更新

- v2 录播目录、能力协商、短期播放令牌、会话刷新/取消及逐项批删；身份绑定 recording_id/source_version/asset_version。
- Web 使用 OpenAPI 类型化客户端、携带 Bearer 的受控 SSE，同页/跨页认证变化立即取消旧流；首次同源认证初始化后再挂载页面。
- 观看历史严格匹配来源版本和服务器，避免文件被替换后错误续播；统计优先显示服务端核验文本，缺失时间显示“时间未知”。
- 历史补齐默认只预览，摘要确认后复用原持久准备队列，支持限速、暂停/恢复、来源变化失效及低空间暂停；删除执行任务后可重新规划，保留预览审计。
- 五项独立审查 Important 已修复：跨会话资产绑定、SSE认证变化、治理任务删除恢复、续播身份、房间统计。

## 验证

- Web lint、七组契约脚本、make build-web dev、make lint、make test、go test -race ./...通过。
- 鸿蒙源码90/90、Hypium107/107与签名构建通过；指定录播MatePad时间线仍待设备连接。
- iOS签名/模拟器构建与契约通过。指定5,634,539,067字节录播的SHA256一致副本，真实iPhone冷/热总体首帧约0.75秒；50%/95%跳转、240秒暂停刷新保持位置/倍速、超过旧令牌期限播放、退出取消通过。
- 大录播实际播放的是原准备策略输出的608x1080p30 H264 Main/AAC LC资产；原始源为1080x1920p60，未宣称原FLV直接解码。

## 升级说明与已知限制

- 先备份配置、数据库和二进制，再替换。保持录制/鉴权策略，配置路径应显式指定，更新不自动开启历史批量转换或删源。
- 旧FLV需要已准备且能力匹配的播放资产。尚未准备的旧库在v2入口明确提示“需完成准备”；不能将此版称为旧库无需准备即可播放。历史治理先预览，真实批量执行另行授权。
- 未确认的过期dry-run预览暂未设置清理/保留上限，持续创建预览会增长SQLite；后续补审计保留策略。
- 跨端设备性能只代表上述实际验证范围；HDR→SDR完整正向环境、其他媒体矩阵及MatePad指定文件验收仍待补齐。

本RC仅发布服务端/Web构建；iOS与鸿蒙应用的独立签名分发不包含在这些压缩包内。
