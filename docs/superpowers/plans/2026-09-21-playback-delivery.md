## 范围与结果

延续 9 月 7 日 A 阶段核心修复，本次补齐服务端资源配置、探测缓存、延迟日志，以及 B 阶段录后 MP4 的安全发布和播放关联。双端真机验收、C 设备能力分流、D 历史库批量治理不在本次完成范围；不能将本报告理解为全部路线图已交付。

### HLS

- 保留统一任务拥有者、FIFO 有界队列、唯一 Wait、首批清单可读、失败/partial 区分、关闭回收以及读租约机制。
- 新增并接入并发、排队容量、最低空闲磁盘、读宽限配置；旧 YAML/JSON 自动补默认值，显式禁用值保留。
- HLS 与录后 MP4 共用进程内重媒体工作预算；既有持久化后处理队列和 HLS 队列分别负责排队。不会限制正在录制的进程，也不涵盖用户自定义命令。
- 开始转换前及转换过程中检查 HLS 缓存所在文件系统的剩余空间，低于阈值停止写入并回收进程。
- 探测成功结果保存到 AppDataPath 下的 `media-probe`，缓存键包含来源和 ffprobe 的绝对路径、大小、纳秒修改时间。探测失败不缓存，来源/工具变化失效；最多 512 条、7 天有效。缓存写失败不阻断正常播放。
- 日志区分排队、公共资源等待、探测、首批可读和结束耗时。服务端首批可读不是播放器首帧。
- resolver 的重试秒数包含读宽限，避免固定五秒与实际可重试时间不符。
- 启动清缓存移到 HTTP 监听之前，避免清掉启动窗口内新建的作业。

### MP4 与播放关联

- 复用录制结束后的持久化 pipeline。兼容 H.264/AAC 输入使用 copy + faststart；无音轨允许，其他编码在此阶段明确报错保源。
- 唯一隐藏临时文件，检查轨道、可读包、源/产物时长和 moov 前置后才发布；拒绝覆盖已有不相关媒体。已有 MP4 也检查，非 faststart 生成独立 `.prepared.mp4`。
- `<产物>.playback.json` 记录来源/产物版本。列表按原来源路径保持一条录播，resolver 优先返回已验证 MP4；观看记录仍使用原 `video_path`。
- 原来源删除后，旧播放路径、旧缩略图路径继续映射到产物。旧 HLS 地址优先沿用版本一致的活动/已完成作业，无可用旧作业时从 MP4 生成 HLS。
- 单文件删改不会隐式连带删除另一份媒体。原来源存在时操作来源并解除关联，剩余产物以独立 MP4 展示；原来源缺失时旧路径操作对应产物。
- 修复 `/files/` 未被签名认证入口接纳的问题；仍校验 GET 方法、路径、到期时间和签名。

## 有效配置与运行行为

```yaml
hls_cache:
  max_concurrent: 3       # HLS 上限，同时作为 HLS+录后MP4 的公共并发预算
  max_queued: 64          # HLS 待执行队列容量
  min_free_space_gb: 1    # HLS 所在文件系统，0 禁用
  read_grace_seconds: 60  # 无活动读者后的保护期，0 禁用宽限，读租约仍有效
```

并发合法范围 1–32，队列 1–1024。最低空间不得为负数、NaN 或 Infinity；读宽限不得为负数。原 `max_age_hours`、`max_total_size_gb` 保留。

当前工作区配置已有 `on_record_finished.convert_to_mp4: true`、`delete_flv_after_convert: false`；未改写用户配置。代码默认仍保留原有 opt-in 设置，已有显式关闭配置不会被强行打开。录制完成时使用解析后的房间有效配置入队；实际 pipeline 顺序为 FLV 修复、MP4、封面、上传、自定义命令，启用与否分别由对应配置控制。不能把旧 YAML 中“自定义命令替代内置转换”的注释当作当前调用链事实。

## 验证证据

最终命令与结果在完成检查后更新。已执行的集成测试包括：

- 真实 FFmpeg 生成 H.264/AAC 录播，走 MP4 阶段、删除测试源文件、原路径 resolve、持久化观看记录读取。
- 通过实际文件认证 middleware 和本地 Go 反向代理请求签名 GET；首、中、尾部 Range 返回 206、准确 Content-Range 和字节内容；无签名/篡改签名返回 401。
- 原来源删除后的单/批文件删除与重命名；保留另一媒体，解除旧身份；旧 HLS 清单与分片可读并保持活动作业。
- HLS 真实子进程生命周期、资源队列、低空间不启动进程、读宽限、关闭、partial、并发去重与回收互斥。
- 配置迁移和往返；测试加载配置改用临时副本，防止迁移回写真实 config.yml。

## 边界与回退

本地 Go 反向代理测试不能替代用户生产代理/CDN；未验证生产网络、真机播放、50%/末尾 seek、签名刷新续播或首帧 P95。没有测量证据支持“首帧必定两秒以内”。

媒体校验读取包并检查容器，不是逐帧完整解码；长录播验证预算、极长 GOP、慢磁盘、真实磁盘满和断电场景仍需样本验收。非 H.264/AAC 的离线兼容转换、HDR 色调映射与客户端能力协商属于 C。

停用新增录后 MP4 可沿用 `convert_to_mp4: false`；不会删除已有媒体。已生成的 MP4 是标准文件，但旧版本服务端不识别来源 sidecar，因此退回旧版本时源已删除的旧 relPath 不保证继续解析。不要为回退清理源文件或媒体产物。本次没有生成并部署可验证的回退镜像，基线 `261ad73` 本身曾有编译/生命周期问题，不将其声明为可直接运行的回退版本。
